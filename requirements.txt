# Pneumonia CDSS – Python Dependencies
# Strategy: >=current_stable, <next_major
#
# ✅ Gets security/bug-fix patches automatically
# ✅ Protected from silent breaking changes on major version bumps
# ✅ Reproducible across every Streamlit Cloud cold start
#
# Key dependency decisions:
#
#   NO ultralytics package:
#     best.pt is a YOLOv5 model. ultralytics (YOLOv8 API) explicitly rejects
#     YOLOv5 weights. Model is loaded via torch.hub which downloads the
#     correct ultralytics/yolov5 repo automatically at first cold start.
#
#   NO opencv-python-headless:
#     torch.hub/yolov5 pulls in opencv-python (full build) as a transitive
#     dependency. headless + full = pip conflict. The system lib it needs
#     (libgthread-2.0.so.0) is satisfied by libglib2.0-0t64 in packages.txt.
#
#   numpy <2:
#     NumPy 2.x has breaking C-API changes. YOLOv5 not yet confirmed
#     compatible. Cap stays until upstream confirms support.
#
# Last reviewed: March 2026
