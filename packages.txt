# ─────────────────────────────────────────────────────────────────────────────
# Pneumonia CDSS – Streamlit Cloud System Packages (packages.txt)
#
# Streamlit Cloud reads this file and runs: apt-get install -y <each line>
# before installing Python requirements.
#
# WHY THESE PACKAGES:
#   libglib2.0-0      → provides libgthread-2.0.so.0 and libglib-2.0.so.0
#                        (required by some torch/torchvision native extensions)
#   libgl1            → provides libGL.so.1
#                        (required by torchvision C++ extensions)
#   libgomp1          → OpenMP runtime for PyTorch parallel ops
#
# NOTE: With opencv-python-headless these are NOT needed for OpenCV itself,
# but torch/torchvision native extensions may still link against them.
# Declaring them explicitly makes the deployment deterministic and robust.
# ─────────────────────────────────────────────────────────────────────────────
libglib2.0-0
libgl1
libgomp1
